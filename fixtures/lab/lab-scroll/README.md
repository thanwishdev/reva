# Fixture Lab, group C: scroll maps and scroll smoothing

Own fixture pages with known truth for the M2 fitter (`docs/design/M2-fitter.md` section 11, routes of section 15 group C).
Everything here is public-safe: own parameters, no value from a captured site (PLAN section 4 list), no site-derived file.

| Route | Page | Mechanism (truth) | Driver | Params in the grid |
|---|---|---|---|---|
| M01 | `routes/m01.html` | linear scroll map `p = 1 - clamp(-top, 0, H) / H`, written in the shared rAF, no smoothing | scroll | start offset `o` px, span `h` vh (5 points) |
| M02 | `routes/m02.html` | smoothstep target over the bottom edge 0.85 to 0.25 vh + per-frame EMA, snap 1e-3 | scroll | `alpha` 0.08 .. 0.40 (5); plus `write` q3 / q2 (10) |
| M03 | `routes/m03.html` | `a`: snap on rise, EMA on fall; `b`: EMA on a falling target; `p = max(a, b)` | scroll | `aDown`, `aExit` (5 pairs) |
| M04 | `routes/m04.html` | pinned scrub (easeInOutCubic over 1.3 vh) + EMA on scale / translate / origin (written `toFixed(3)` / `(2)`) + 5-tab index with +/-0.3 hysteresis | scroll | `alpha` 0.07 .. 0.38 (5) |
| M05 | `routes/m05.html` | wheel-latched easeOutCubic tween, `preventDefault`, retarget from the current value, scroll pinned while it runs | real CDP wheel | `dur` 320 .. 1060 ms (5) |
| M09 | `routes/m09.html` | Lenis 1.3.26 (vendored, MIT), dt-aware damp | real CDP wheel | `lerp` 0.06, 0.10, 0.15 |
| M09b | `routes/m09b.html` | own legacy per-frame lerp scroller | real CDP wheel | `lerp` 0.10, 0.28 |

M10 (inertia) belongs to group B and View Transitions / FLIP (M17, M18) to group A in the route table; this group does not build them.

## Files

- `core.js` pure math shared by the pages and `refsim.mjs` (no DOM, no globals); `routes/` pages (module scripts, `lib.js`, `base.css`, `vis.css`).
- `refsim.mjs` `simulate(routeId, params, ctx)`; `ctxFromTake({take, data})` builds ctx from a loaded take (fills the frame index of
  hx wheel events from the page-side wheel log until recorder extension X2 lands).
- `truth.mjs` `truth(routeId, params, regime, variant, ctx?)`; `truth/<id>.json` are review files generated by `tools/gen-truth.mjs`.
- `routes.json` route table (params grid, traces, watch selectors, metrics); `traces/` generated by `tools/gen-traces.mjs`; `plan.mjs` regimes, scenario specs and planned frames.
- `parity.mjs` the parity proof (records `hx` takes, compares refsim with the rendered channels); `serve.mjs` blind static server for local runs.
- `vendor/lenis.mjs` + `vendor/LICENSE-lenis`: lenis@1.3.26 `dist/lenis.mjs`, unmodified (the page patches `updateClassName` at runtime so no library class lands on `<html>`).
- `test/` unit tests (`core`, `files`) and the browser parity test (`parity.test.js`; `LAB_PARITY=full|grid` widens it).

## Conventions

- Pages are blind: params only from `location.hash` (`#p=<base64url JSON>`, see `core.js` `encodeParams`), ids and custom properties are single letters,
  no classes, no data attributes, no truth hook. Drivers live in `routes.json`, not in the page.
- Channels: custom properties via `setProperty` on `#c` (and `#k` in M04) mapped by `calc()` to transform and opacity; M04 also pins `#c` with `position: sticky`.
- Traces are recorder action lists starting with a 500 ms hold; holds are multiples of 100 ms. A wheel event costs one frame in `hx`, so a wheel that follows a
  hold of 200 ms lands 200 ms + 1 frame later; refsim uses the logged frame index, so truth is exact either way.
- refsim needs contiguous frames. For R6 pass the frames of the take before rows are dropped.
- Scroll offsets are integers in the browser: M09 / M09b write the unrounded position to `--y` and the window scroll position is `round(--y)`.
